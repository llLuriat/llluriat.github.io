HealthFlow

TCC no SESI SENAI, 2026
Equipe de 5 pessoas

O que é

Planet9 Screening Lab

Iniciação científica, IC Astros e Aventuras

O que é
Um simulador em Python que testa se certas órbitas de objetos distantes podem ser explicadas pela existência de um nono planeta.
O que eu fiz
Programei a simulação e uma triagem automática de candidatos. Rodei também um grupo de controle, sem o Planeta 9, para comparar. Os resultados podem ser conferidos e retomados se uma execução parar. Há testes automatizados e um painel para acompanhar o andamento.
Resultado
Trabalho submetido à FEBRACE. Código aberto no GitHub.
Tecnologias
Python, REBOUND, método de Monte Carlo, pandas e pydantic.

Projeto pessoal

O que é
Um programa em Python que transforma fotos de folhas, impressas ou escritas à mão, em texto digital usando um modelo de IA.
Por que é interessante
Foi pensado para cerca de 15 mil folhas. Por isso reduz o tamanho das imagens, continua de onde parou se algo falhar, marca os trechos ilegíveis e compara dois modelos de IA.
Tecnologias
Python e API de modelo de IA.
